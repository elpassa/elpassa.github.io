Privacy Policy

Sync Excel Drive is a private tool used only by its owner on their own computer.

Google user data accessed

The app requests only the Google Drive drive.file scope. With this scope it can create, read and update only the files it creates itself. It cannot see or access any other file in the user's Google Drive.

How the data is used

The app uses this access only to upload an Excel file from the owner's computer to the owner's Google Drive and to update that same file when it changes.

Storage

The OAuth access token is stored only on the owner's computer. The app has no server: no Google user data is sent to, stored on or processed by the developer or any third party.

Sharing

Google user data is not shared, sold or transferred to anyone. Any sharing of the file on Google Drive is done manually by the owner through Google Drive.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.

Contact

For questions, use the support email shown on the Google sign-in consent screen of this app.
