Sync Excel Drive

Sync Excel Drive is a private, personal-use tool. It uploads a single Excel file from the owner's computer to the owner's own Google Drive, so that the file can be viewed online in Google Drive and Google Sheets.

What it does

  • Uploads one Excel file to Google Drive and keeps it up to date by replacing the content of the same file.
  • Uses only the drive.file permission: it can access only the files it creates itself, not the rest of the user's Google Drive.
  • Runs only on the owner's computer. There is no server, no account system and no public service.

See the Privacy Policy.
